## Добавление Redis для кэширования запросов

### Docker
- Добавил сервисы для БД, Tomcat и Redis (см. docker-compose.yaml)

### Что я буду кэшировать?

Логичнее всего кэшировать запросы get all для каждой сущности: при большом количестве записей они достаточно тяжёлые. Кроме того, из-за WebSocket после любого изменения объекта все активные клиенты одновременно запрашивают списки заново, так что кэширование будет очень кстати.
